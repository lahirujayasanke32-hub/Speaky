APK build (no PC tools needed):
1. Create a free GitHub account, make a new repository, upload ALL files of this folder
   (including the hidden .github folder, www, package.json, capacitor.config.json).
2. Open the repo > Actions tab > "Build APK" > Run workflow (it also runs on every upload).
3. After ~5 minutes open the finished run > Artifacts > download SpeakUp-apk, unzip, install app-debug.apk.
